# PythonAiFinalProject
# Фінальний проєкт: Калькулятор медичної страховки (Medical Insurance)

Проєкт спрямований на прогнозування річних медичних витрат клієнтів за допомогою методів машинного навчання та регресійного аналізу.

## Опис завдання
Проєкт базується на відкритому датасеті Medical Insurance (дані застрахованих осіб у США). Основна мета — дослідити вплив різних факторів (вік, індекс маси тіла, наявність шкідливих звичок) на вартість медичного страхування та навчити кілька моделей прогнозувати ці витрати.

## Використані технології та бібліотеки
- Python
- Google Colab (середовище розробки)
- Pandas & NumPy (обробка та аналіз даних)
- Scikit-Learn (моделювання та метрики)
- Matplotlib & Seaborn (візуалізація даних)

## Моделі та результати
У проєкті реалізовано та порівняно три підходи:
1. Лінійна регресія (Linear Regression)
2. Поліноміальна регресія (Polynomial Regression, degree=2)
3. Дерево рішень (Decision Tree Regressor)

Оцінка якості моделей проводилась за допомогою коефіцієнта детермінації (R2 Score). Нелінійні моделі (дерево рішень та поліноміальна регресія) показали вищу точність за рахунок здатності враховувати складні взаємозв'язки між факторами (наприклад, комбінацію куріння та високого індексу маси тіла).
